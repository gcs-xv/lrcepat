# Rekap Poli BM — WA Parser (Streamlit)

Aplikasi Streamlit untuk:
- Upload chat WA (.docx/.txt)
- Parsing blok pasien "XX. Nama : ..."
- Deteksi **BAKSOS** vs non-BAKSOS
- Rekap otomatis: Total, Tindakan, Konsultasi, Terjaring GA, VIP, Baksos
- Output teks siap kirim + download .txt

## Jalankan lokal
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
